<h5>Instruções para AVALIAÇÃO III – CSS</h5>
<p>Procedimentos e regras que precisam ser seguidos alcançar a nota 10 (dez)</p>
<p>1. Corrigir toda a indentação do código HTML conforme explicado várias vezes em sala de aula. (1 ponto)</p>
<p>2. Adicionar os metas tags principais (o que foram mostrados ao longo da disciplina) e o ícone da página. (1,5 pontos)</p>
<p>3. Criar e linkar o arquivo CSS ao HTML o qual precisa estar na pasta css. (0,5 pontos)</p>
<p>4. Não usar Javascript nessa fase.</p>
<p>5. Compacte em. zip ou .rar todos os arquivos e / ou pastar envolvidas no projeto (1 ponto)</p>
<p>6. O nome do arquivo postado deve ser OBRIGATORIAMENTE seu próprio nome completo sem acento e sem espaço com a primeira em maísculo. Ex: Giacomo_Antonio_Atlhoff_Bolan.zip (1 ponto)</p>
<p>7. Se dois ou mais alunos tiveremm o código CSS iguais, será dado a nota será ZERO sem direito de recuperação.</p>
<p>8. Qualquer aluno pode ser chamado para explicar a sua avaliação e o seu funcionamento, o não conhecimento do seu “próprio código” CSS levará a nota será ZERO sem direito de recuperação.</p>
<p>9. Baixem o vídeo com a explicação e demonstração do resultado.</p>
<p>10. Baixem o projeto inicial que contém o ponto de partida.</p>
<p>11. Seja cuidadoso(a) nos detalhes vistos no vídeo e passado para o código CSS</p>
<p>12. Siga a risca o visual da página apresentado no vídeo. Não invente estilo visual, apenas faça igual o do vídeo. (3 pontos)</p>
<p>13. Comece sempre das regras mais genéricas até as mais específicas.</p>
<p>14. Cuida da indentação no CSS.</p>
<p>15. Não é necessário adicionar nenhuma tag HTML para reestruturar o código, é possível resolver a atividade sem nenhuma adição. Mas fique à vontade caso precise fazer.</p>
<p>16. Não é necessário adicionar nenhuma class nem id para resolver a atividade. Mas fique à vontade caso precise fazer.</p>
<p>17. O aluno(a) deve procurar um servidor gratuito para postar o resultado da aplicação. (1 ponto)</p>
<p>18. Na postagem final do exercício, crie um arquivo instrução.txt com o link para acessar o resultado (site) postado. Coloque esse arquivo na raiz, junto com o index.html. (1 ponto)</p>
